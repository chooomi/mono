# MONO

Концептуальный сайт модульной архитектуры.

Опубликованная версия: https://chooomi.github.io/mono/

Три модели домов, интерактивные планировки, конфигуратор и сохранение спецификации. Все цены и характеристики демонстрационные, заявки не отправляются.

Этот репозиторий содержит только публичные файлы сайта. Исходный проект с тестами и сборкой сохранён отдельно в локальной папке mono.
